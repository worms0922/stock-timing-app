[네이버 금융 실시간 연동] 트리플 타점 & 실시간 자동분석(TOP 20) 시스템

1. 실시간 자동분석 (Screener) 신규 기능:
   - 상단 [🎯 실시간 자동분석 TOP 20] 버튼으로 언제든 열고 닫을 수 있는 전용 스캐너 탑재
   - 장중 / 장마감 자동 판별 기준:
     * 장중 (09:00 ~ 15:30): 미완성 당일 캔들의 흔들림을 배제하기 위해 [전일 종가 완성봉] 기준으로 안정적 분석
     * 장마감 후 (15:30 이후 및 주말): 마감 확정된 [금일 종가 완성봉] 기준으로 분석
   - 일봉 / 주봉 / 월봉 탭별 각 20개씩 알고리즘 타점 부합 종목 자동 추출
   - 정렬 기준: 거래량이 가장 많은 순서로 1위~20위 정렬 (작전세력/유동성 리스크 배제 및 우량주 중심 투자)
   - 표에서 종목을 클릭하면 메인 차트에 즉시 해당 종목과 타점 분석이 로드됩니다.

2. 기존 앱 아웃라인 100% 보존:
   - 사용자분께서 선호하시는 기존 2-카드 대시보드(좌측 상태창, 우측 3대 타점 진단) 및 캔들 차트 레이아웃 원형 유지
   - 매수 타점(▲), 과열 익절 타점(▼), 손절 경고(✕) 시각화 지원

3. 실행 방법:
   - 폴더 내 run.bat 파일을 더블클릭하시면 브라우저(http://localhost:8080)가 열립니다.
