# 토스 수급 복합분석 + 실시간 스캘핑 관찰창

본인 전용 분석 사이트 수정본입니다. 원본 ZIP은 변경하지 않았습니다.
주문·계좌 조회 API는 호출하지 않습니다. 모든 금융 데이터는 토스 시세 API에서 받습니다.
실제 API 키가 없는 상태에서 공식 응답 형식과 테스트 데이터로 검증했습니다.
배포와 실제 계정 연결은 아직 하지 않았습니다.

## 변경 내용

- 기존 일봉·주봉·월봉 차트 유지. 토스 일봉을 주봉/월봉으로 합산합니다.
- 수급 복합점수: 수급 60%, 기술적 매수조건 40%.
- 수급점수 4조건 각 25점: 외국인 순매수 양수, 기관 순매수 양수,
  최근 5거래일 외국인+기관 합계 양수, 기준일 실제 거래량 대비 합계 순매수 1% 이상.
- 외국인·기관 수급은 주식 수 기준입니다. 수정주가 거래량을 분모로 섞지 않습니다.
- 이력/수급 누락 또는 시세와 수급 기준일 불일치 시 종합판정을 보류합니다.
- 당일 투자자 수급은 잠정치입니다. 개인 수급 포함 여부로 잠정 표시하며,
  최종 확정 플래그를 API가 제공하는 것으로 가정하지 않습니다. 저녁 이후 정정될 수 있습니다.
- 기존 매도/손절 조건을 유지하고, 종합판정 화면에서 과열·추세 이탈을 우선 표시합니다.
- 과거 차트 화살표는 원래의 기술적 분석 결과입니다. 최신 수급을 과거 신호에 소급 적용하지 않습니다.
- 관심 20종목 스캐너: 수급 종합점수 순, 동일 점수 시 기술 점수·거래량 순.
  전체 시장 스캐너가 아닙니다. 수급 없는 종목은 뒤에 배치합니다.
- 실시간 창: 토스 WebSocket 체결·호가 수신, 화면 2초 갱신, 분봉 최대 20초 캐시.
- 조건 각 25점: 최근 20개 완료 분봉 근사 VWAP 상회, 거래량 1.5배,
  직전 5개 완료 분봉 고점 돌파, 상위 3호가 매수잔량 비중 55% 이상.
  75점 이상이면 후보로 표시합니다. 공식 체결강도는 제공하지 않습니다.
- 근사 VWAP은 (고가+저가+종가)/3 × 분봉 거래량으로 계산한 최근 20봉 값입니다.
  당일 전체 체결로 계산한 정확한 VWAP과 다릅니다.
- 체결·호가가 30초 이상 오래되거나 분봉이 150초 이상 오래되면 판정을 보류합니다.
  완료 당일 분봉이 20개 미만이거나 호가 스프레드가 0.2% 초과여도 보류합니다.
  비활발한 종목·휴장·장 마감에는 데이터 대기/지연으로 표시될 수 있습니다.
- 점수/임계값은 검증 전 휴리스틱입니다. 수익 확률이나 수익 보장이 아닙니다.
- 서버 시간은 한국 시간으로 처리합니다. 날짜 변경을 기다리지 않고 받은 최신 데이터를 반영합니다.
  데이터 제공처의 잠정치·확정치 반영 시각 자체를 앞당길 수는 없습니다.
- 메인 차트 자동 갱신 60초. 스캔 결과/수급 캐시 60초. 강제 스캔도 원본 캐시가 적용됩니다.
- 시세 수신 실패 시 가상 가격을 생성하지 않습니다.
- 개인용 HTTP Basic 로그인 적용. 토스 키/액세스 토큰은 브라우저에 보내지 않습니다.

## Render 배포 설정

1. 이 폴더 파일을 기존 GitHub 프로젝트에 반영합니다. 먼저 원래 배포를 백업하세요.
2. Render의 환경변수(Secret)에 아래 네 항목을 직접 등록합니다. 키를 소스나 채팅에 넣지 마세요.
   - `TOSS_CLIENT_ID`: 토스에서 발급받은 client_id
   - `TOSS_CLIENT_SECRET`: 토스에서 발급받은 client_secret
   - `APP_USERNAME`: 본인용 사이트 로그인 이름 (콜론 제외)
   - `APP_PASSWORD`: 본인용 사이트 로그인 비밀번호 (12자 이상)
3. Python 3.12, Build Command `pip install -r requirements.txt`, Start Command `python app.py`.
   Health Check Path는 `/api/health`, 프로세스/인스턴스는 하나로 운영합니다.
4. 서버의 실제 외부 접속 IP를 토스 WTS → 설정 → Open API → 허용 IP 관리에 등록합니다.
   토스 공식 FAQ는 고정 IP를 확보하라고 안내합니다. Render의 기본 출구는 공유 IP 대역이며
   IP가 바뀔 수 있으므로, 해당 대역 등록 지원 여부를 먼저 확인하거나 고정 출구 IP를 마련해야 합니다.
   고정 IP 서버나 고정 IP 프록시 사용도 가능합니다. 이를 확인하기 전 Render 연결 성공을 보장할 수 없습니다.
5. HTTPS 사이트 주소에서 본인용 로그인 이름/비밀번호로 접속합니다.
6. 종목 조회 후 수급 기준일과 수신 시각을 확인하고 실시간 창을 엽니다.
   최초 구독에는 시간이 걸립니다. 데이터 기준 시각이 최신인지 확인하세요.

계좌당 WebSocket 연결은 최대 2개입니다. 이 앱은 한 프로세스에서 연결 하나를 사용합니다.
스캘핑 구독은 가장 최근에 선택한 종목 하나입니다. 여러 탭에서 서로 다른 종목을 열면
선택 종목이 서로 바뀌므로 실시간 분석 탭 하나를 사용하세요.
연결이 끊기면 재연결하고 REST 스냅샷을 다시 받습니다. 토스 체결 스트림은 유실될 수 있으며
누적 거래량이나 매수/매도 구분을 제공하지 않으므로 체결 합산으로 이를 만들어내지 않습니다.

## 과거 이력과 서버 운영

토스 공식 FAQ 기준 국내 시세 이력은 2022-11-23 이후입니다.
60월/120월/200월 지표 등은 이력이 부족하면 계산할 수 없습니다.
월봉을 처음 조회하면 여러 페이지를 받아야 해서 시간이 걸릴 수 있습니다.
장중 화면을 닫아도 현재 선택한 종목의 스트림은 서버가 실행되는 동안 유지됩니다.
무료 Render는 유휴 중단이 있어 연속 수신/분석 저장을 보장하지 않습니다.
PC가 꺼져도 계속 수신하려면 상시 실행되는 서버와 고정 출구 IP가 필요합니다.
이 버전은 신호/체결 이력을 DB에 영구 저장하지 않습니다.

`.env.example`은 항목 안내용입니다. 이 앱이 `.env`를 자동으로 읽지는 않습니다.
로컬에서는 프로세스 환경변수를 설정한 뒤 `pip install -r requirements.txt`, `python app.py`를 실행합니다.
`run.bat`는 PATH에 Python이 등록된 Windows 환경에서 사용할 수 있습니다.
외부 접속은 HTTPS를 제공하는 서버에서 사용하세요.

## 검증

`python -m unittest -v test_analysis`

검증 항목: 미래 수급 제외, 누락 수급 판정 보류, 분봉 종료 시각 처리,
시세 지연 판정 보류, 페이지 중복 제거/시간순 정렬, 종목 변경·구독 오류,
키 미설정과 종목코드 검증. 실제 키로 REST/WS 인증·허용 IP·실시간 데이터를 최종 확인해야 합니다.
